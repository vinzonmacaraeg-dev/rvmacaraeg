# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly known as Google Cloud, is a cloud computing service developed by Google. It offers a wide range of services, including computing, storage, databases, networking, artificial intelligence, machine learning, and application development. Organizations can use Google Cloud to develop, deploy, and manage applications through Google’s worldwide cloud infrastructure.

## Global Infrastructure

Google Cloud operates through a worldwide infrastructure consisting of regions and zones. Regions are specific geographic locations where Google Cloud resources are available, while zones are individual locations within those regions where resources can be deployed. This global setup enables organizations to run applications with improved performance, availability, and scalability.

## Cloud Management Console

The Google Cloud Console is a web-based platform used to access and manage Google Cloud services and resources. Through the console, users can create, configure, and monitor virtual machines, storage, databases, networks, and other cloud resources.

## Four Core Services

### Compute Engine

Compute Engine provides scalable virtual machines that can run applications and workloads on Google's infrastructure.

### Cloud Storage

Cloud Storage is an object storage service used to store files, backups, media, and other types of data.

### Cloud SQL

Cloud SQL is a managed relational database service that supports database systems such as MySQL, PostgreSQL, and SQL Server.

### Google Kubernetes Engine (GKE)

Google Kubernetes Engine is a managed Kubernetes service used to deploy, manage, and scale containerized applications.

## Three Advantages

1. **Strong AI and Machine Learning capabilities** – Google Cloud provides services and tools for developing and deploying AI and machine learning applications.
2. **Kubernetes expertise** – GKE provides a managed Kubernetes environment for containerized applications.
3. **Global infrastructure** – Google Cloud has a global network and infrastructure that supports applications used by customers in different locations.

## Typical Enterprise Use Cases

Organizations use Google Cloud for a variety of purposes, including hosting web and mobile applications, analyzing data, developing artificial intelligence and machine learning solutions, managing databases, and storing large amounts of information. It is also well-suited for building cloud-native applications with Kubernetes and other modern cloud technologies.
