# Azure Research

## Brief Overview

Microsoft Azure is a cloud computing platform created by Microsoft that offers a variety of services, including computing, storage, databases, networking, security, artificial intelligence, and application development. Azure enables organizations to develop, deploy, and manage applications using Microsoft's cloud infrastructure.

## Global Infrastructure

Azure operates through a global infrastructure made up of geographic regions and availability zones. Each region contains data centers that deliver cloud services to users in different locations around the world. This worldwide infrastructure helps organizations enhance application performance, availability, and reliability.

## Cloud Management Console

The Azure Portal is a web-based platform that allows users to create, configure, monitor, and manage Azure resources. Through the portal, users can handle virtual machines, databases, storage, networking, security, and various other cloud services.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual servers that can run Windows or Linux operating systems and host different applications and workloads.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for storing large amounts of unstructured data such as documents, images, videos, and backups.

### 3. Azure SQL Database

Azure SQL Database is a managed relational database service based on Microsoft SQL Server technology. It reduces the need to manage database infrastructure manually.

### 4. Azure Virtual Network

Allows Azure resources to communicate securely with each other and with on-premises networks.

## Three Advantages

1. *Microsoft integration* – Azure works closely with Microsoft products such as Windows Server, Microsoft 365, and other Microsoft technologies.
2. *Scalability* – Organizations can increase or decrease cloud resources based on their workloads.
3. *Hybrid cloud support* – Azure provides services that help organizations connect their existing on-premises infrastructure with cloud resources.

## Typical Enterprise Use Cases

Organizations use Azure for hosting websites and applications, running both Windows and Linux servers, managing databases, storing data, developing software, and implementing artificial intelligence solutions. Azure also supports hybrid cloud environments, making it a suitable choice for businesses that already rely on Microsoft products and technologies.
