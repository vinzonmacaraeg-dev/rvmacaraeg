## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS provides a wide variety of cloud services, including computing, storage, databases, networking, security, and many other solutions. Its extensive selection of services makes AWS a flexible option for organizations with different types of cloud computing needs.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure offers excellent integration with Microsoft products and services. It is particularly well-suited for organizations that already use Windows Server, Microsoft 365, and Active Directory, making it easier to connect and manage their existing IT infrastructure.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud Platform (GCP) is especially strong in Artificial Intelligence, Machine Learning, and Kubernetes technologies. Its services are well suited for organizations that develop AI solutions and use modern cloud-native applications and workloads.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it offers a wide range of cloud services that can support various applications and business needs. Its extensive selection of tools and services also provides plenty of opportunities to develop practical skills and expand my knowledge of cloud computing.
