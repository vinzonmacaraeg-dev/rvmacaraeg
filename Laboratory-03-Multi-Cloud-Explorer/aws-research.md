# AWS RESEARCH

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform offered by Amazon that provides a wide range of services for organizations. These include computing, storage, databases, networking, security, analytics, and other IT solutions. AWS enables businesses to access cloud resources and services without needing to manage and maintain their own physical servers.

## Global Infrastructure

AWS operates through a global infrastructure consisting of Regions and Availability Zones. Regions represent different geographic locations around the world, while Availability Zones are separate and isolated facilities within each Region. This infrastructure allows organizations to deploy their applications closer to their users while improving system availability, performance, and reliability.
## Cloud Management Console

The AWS Management Console is a web-based platform that allows users to access and manage various AWS services. Through the console, users can create and configure cloud resources, monitor services, adjust security settings, and manage their overall cloud infrastructure.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that can be used to run applications and workloads.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides scalable object storage for files, data, backups, and other digital content.

### 3. Amazon RDS

Amazon Relational Database Service (RDS) makes it easier to set up, operate, and manage relational databases in the cloud.

### 4. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows users to create a logically isolated network where AWS resources can be deployed and controlled.

## Three Advantages

1. *Wide range of services* – AWS provides many services for different computing and business requirements.
2. *Scalability* – AWS resources can be increased or decreased depending on the workload.
3. *Global infrastructure* – AWS has infrastructure in many geographic locations, allowing organizations to deploy applications closer to their customers.

## Typical Enterprise Use Cases

Businesses use AWS for a wide range of purposes, including hosting web and mobile applications, storing and backing up data, managing databases, developing software, performing data analytics, and implementing artificial intelligence solutions. AWS also supports large-scale business applications and helps organizations move their existing IT systems from physical servers to cloud-based infrastructure.
