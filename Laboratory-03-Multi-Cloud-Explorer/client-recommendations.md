# Client Recommendations

## Client A - Startup Company

### Recommended Platform: (AWS)

AWS is a good option for the startup because it offers a wide range of cloud services that can support the growth of a mobile application. The company can begin with limited resources and scale them up as the number of users increases. AWS also reduces the need to maintain physical servers, making it a flexible and cost-effective choice for a startup with a limited budget.

### Recommended Services

- Amazon EC2 - Compute
- Amazon S3 - Object Storage
- Amazon RDS - Relational databases

---

## Client B - University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the most suitable option for the university because it already relies on Windows Server, Microsoft 365, and Active Directory. Azure works well with these existing Microsoft technologies and identity services. The university can gradually move selected services to the cloud while maintaining its current infrastructure, making the transition more manageable and efficient.

### Recommended Services

- Azure Virtual Machines - Virtual Machines
- Microsoft Entra ID - Identity and Access Management
- Azure SQL Database - Managed Data

---

## Client C - AI Research Company

### Recommended Platform:  Google Cloud Platform (GCP)

Google Cloud is a suitable option for an AI research company because it offers specialized tools and services for artificial intelligence and machine learning. The company can take advantage of Google Cloud’s AI technologies and scalable computing resources for research and development. It also provides Kubernetes services for deploying and managing containerized applications. These features make Google Cloud a strong platform for handling the company’s demanding computing and AI workloads.

### Recommended Services

- Vertex AI - AI and Machine Learning Platform,
- Compute Engine - Virtual Machines And Computing
- Google Kubernetes Engine (GKE) - Kubernetes Management

---

## Client D - Global E-Commerce Company

### Recommended Services

- Amazon EC2 - Compute
- Amazon S3 - Object Storage
- Elastic Load Balancing - Distributes Application

## Multi-Cloud Decision Matrix

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS offers flexible and scalable services that are suitable for growing applications and startups. |
| Enterprise Organization | AWS | AWS provides a wide range of services that can support large and complex enterprise workloads. |
| Microsoft Environment | Microsoft Azure | Azure integrates well with Windows Server, Microsoft 365, and Microsoft identity services. |
| AI / Machine Learning | Google Cloud | Google Cloud provides strong AI and machine learning services such as Vertex AI. |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine (GKE) provides a managed Kubernetes environment for containerized applications. |
| Global Web Application | AWS | AWS provides global infrastructure, automatic scaling, and content delivery services for applications serving users worldwide. |
