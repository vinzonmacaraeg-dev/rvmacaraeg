# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity gave me a better understanding of working with a cloud-based Linux environment using KillerCoda Playground. I learned how to use basic Linux commands and check essential system information. I also gained hands-on experience creating, organizing, and managing files and folders through the terminal. Additionally, I became more familiar with GitHub and how it can be used to build and maintain a Cloud Computing portfolio. Overall, the activity strengthened my practical Linux skills and improved my understanding of cloud computing concepts.

## Objectives

- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

I used KillerCoda to access an Ubuntu Linux environment and created a new user account. I was able to log in with the new account and check essential system information, including my username, current working directory, and hostname. I also explored commands for viewing the Linux distribution, kernel version, CPU, memory, and disk usage. In addition, I practiced creating directories and a Markdown file for my Cloud Computing portfolio. This activity strengthened my Linux skills and helped me better understand how these tools are applied in cloud computing.

## Linux Commands Used

- sudo adduser – Created a new Linux user.
- sudo usermod -aG sudo – Added the user to the sudo group.
- su - – Logged in to the new user account.
- whoami – Displayed the current username.
- pwd – Displayed the current working directory.
- hostname – Displayed the hostname.
- cat /etc/os-release – Displayed Linux distribution information.
- uname -r – Displayed the kernel version.
- lscpu – Displayed CPU information.
- free -h – Displayed memory information.
- df -h – Displayed available disk space.
- mkdir – Created directories.
- cat – Displayed the contents of a file.

This activity helped me gain experience working with a cloud-based Linux environment. I practiced using basic Linux commands and learned how to view essential system information. I also developed my ability to create, manage, and organize files and directories. Through Markdown and GitHub, I learned how to properly document and showcase my technical work. Overall, the activity improved my practical skills and gave me a deeper understanding of Linux and cloud computing.
